# เปิดเว็บและเชื่อมเกม FOCUS SHIFT

สำหรับเว็บที่เปิดจากหลายเครื่องผ่านอินเทอร์เน็ต ให้ใช้ [คู่มือ Vercel และ PostgreSQL](vercel-th.md)

## 1. เปิดเว็บด้วยข้อมูลตัวอย่าง

จากโฟลเดอร์หลักของโปรเจกต์ เปิด PowerShell แล้วรันคำสั่งต่อไปนี้ ใช้ Node.js 24.12 ขึ้นไปในสาย 24

```powershell
cd Analytics
npm.cmd ci
npm.cmd run build
npm.cmd run demo
```

เปิด URL ที่แสดงใน PowerShell ค่าเริ่มต้นคือ [http://127.0.0.1:4311](http://127.0.0.1:4311/) เปิดหน้าต่าง PowerShell ค้างไว้ระหว่างใช้งาน เลือก **ไทย** ด้านบน แล้วกด **ผู้ดูแลระบบสาธิต** หรือ **ผู้สอนสาธิต** ข้อมูลตัวอย่างใช้ฐานข้อมูลของเดโมโดยเฉพาะ

## 2. เปิดเว็บสำหรับเก็บข้อมูลจริง

จากโฟลเดอร์ `Analytics` คัดลอกไฟล์ตั้งค่าตัวอย่างและเปิดแก้ไข

```powershell
Copy-Item .env.example .env
notepad .env
```

ถ้ามีไฟล์ `.env` อยู่แล้ว ให้เปิดแก้ไขไฟล์นั้นโดยตรง ตั้ง `ADMIN_PASSWORD` และ `EDUCATOR_PASSWORD` ให้เป็นรหัสผ่านคนละชุดและยาวอย่างน้อย 16 ตัวอักษร จากนั้นรัน `npm.cmd start` หลังจาก build เว็บแล้ว

- หากต้องการเปิดดูระบบจริงบนเครื่องเดียว ให้ใช้ [http://127.0.0.1:4310](http://127.0.0.1:4310/) ฐานข้อมูลสำหรับเก็บผลจริงจะเริ่มต้นว่าง
- หากต้องการรับผลจากเกม ให้เปิดเว็บและ API ผ่าน HTTPS โดยใช้ชื่อโฮสต์ที่เครื่องผู้ดูแลและ Quest เข้าถึงได้ และใบรับรองที่อุปกรณ์ทั้งสองเชื่อถือ ตั้ง `PUBLIC_ORIGIN` ให้ตรงกับ URL ของ HTTPS และรีสตาร์ตเซิร์ฟเวอร์ Node คู่มือหลักมีตัวอย่างตั้งค่า Caddy ให้ส่งต่อไปยัง Node ที่พอร์ต 4310 [การตั้งค่า HTTPS](../README.md#operate-a-supervised-installation)

## 3. เตรียม Build ให้ส่งผลอัตโนมัติ

**ทีมทำครั้งเดียวตอนเตรียม Build** หลังเว็บออนไลน์แล้ว ตั้ง `GAME_ENROLLMENT_KEY` ใน Vercel สร้างได้ด้วย `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"` จากนั้นใน Unity ไปที่ **Home Focus → Set study server for builds** ใส่ URL หลักแบบ HTTPS และคีย์เดียวกัน แล้วสร้าง Build ใหม่

- **Windows** เลือก Windows ใน **File → Build Profiles** แล้ว Build ส่งทั้งโฟลเดอร์เกมให้เครื่องเล่นเพื่อให้ EXE โหลดไฟล์ประกอบได้
- **Meta Quest** สลับ Build Profile เป็น Android แล้วใช้ **Home Focus → Build Quest APK** ได้ไฟล์ `Builds/HomeFocus-Quest.apk` สำหรับติดตั้งบนเฮดเซต

**ตอนใช้งานที่เครื่องเล่น**

1. เปิด APK หรือ EXE แล้วเลือก **Start and record results** เพื่อยินยอมเก็บผล เกมขอรหัสผู้เล่นใหม่ เช่น `P001` จากเว็บโดยอัตโนมัติ
2. เมื่อจบรอบ เกมแสดงผลและรหัสผู้เล่น พร้อมส่งผลไปยังเว็บ เจ้าหน้าที่ดูได้ใน **ผู้เข้าร่วม** หรือ **รอบกิจกรรม**
3. เกมค้างที่หน้าผลจนกด **Start New Session** แล้วกลับไปหน้าเลือกโหมด หากเลือกเก็บผลอีกครั้ง ระบบจะออกเลขถัดไป เช่น `P002` โดยถือเป็นผู้เล่นใหม่
4. เลือก **Practice without sharing** เพื่อเล่นทดสอบ โหมดนี้ไม่ขอรหัสผู้เล่นและไม่เก็บผลของรอบนั้นในฐานข้อมูล

## ข้อมูลเดินทางอย่างไร

`เริ่มแบบเก็บผล → API ออกรหัสผู้เล่น → เกมส่ง JSON ผ่าน HTTPS → PostgreSQL → เว็บแสดงผล`

การเริ่มรอบแบบเก็บผลต้องออนไลน์เพื่อรับรหัส ถ้าเชื่อมไม่ได้ เลือกลองใหม่หรือเล่นแบบทดลองได้ หากหลุดเน็ตหลังเริ่มรอบแล้ว ผลจะค้างในคิว และเมื่อเปิดรอบเก็บผลออนไลน์อีกครั้ง เกมจะลองส่งรายการที่ค้างไว้ภายในอายุสิทธิ์ ค่าเริ่มต้นคือ 7 วัน API ใช้ ID ของรอบเพื่อบันทึกผลเพียงรายการเดียวแม้ส่งซ้ำ

ฐานข้อมูลออนไลน์ใช้ **Neon PostgreSQL** เดโมในเครื่องใช้ **SQLite** เกมใช้ **UnityWebRequest** ส่ง **JSON** ผ่าน HTTPS ไฟล์ **CSV** สร้างเมื่อเจ้าหน้าที่ส่งออกรายงานจากเว็บ
