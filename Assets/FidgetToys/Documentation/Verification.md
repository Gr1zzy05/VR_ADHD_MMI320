# ผลการทดสอบ FidgetToyDemo

รัน Unity Editor 6000.3.8f1 ใน Batch Mode ด้วย Direct3D 11 บนสำเนาโปรเจกต์ที่ใช้แพ็กเกจเดิม เปิด FidgetToyDemo เข้า Play Mode และจบด้วย exit code 0 ภาพจากกล้องจริงของฉากอยู่ที่ `Tools/FidgetToys/Preview.png` บันทึกรอบสุดท้ายอยู่ที่ `Logs/FidgetToyAcceptance.log` บนเครื่องที่รันทดสอบ

| ตรวจ | ผลที่วัดได้ |
|---|---|
| Import และ Prefab | Unity โหลดฉากพร้อมทั้งสอง prefab และตรวจ GameObject ในฉาก รวมลูกที่ปิดอยู่ พบ Missing Script 0 และไม่พบ C# compilation error ในบันทึก |
| เนย | วัดจากจุดยอดหลัง BakeMesh ได้ 16 × 6 × 4 ซม. บีบและคืนรูปสองรอบ ความสูงลดลงมากกว่า 15% ความกว้างด้านข้างเพิ่มมากกว่า 10% และน้ำหนัก blend shape หลังคืนรูปต่ำกว่า 0.1 จาก 100 |
| Pop It | วัดความกว้างและความยาวกรอบได้ 21.36 ซม. พบศูนย์กลางฟองต่างกัน 28 ตำแหน่งและมีไฟล์เสียงผูกอยู่ |
| การกดฟอง | ทดสอบทีละฟองครบทั้ง 28 ฟอง ตรวจว่ามีเฉพาะฟองที่กดกลับด้าน การกดซ้ำในเฟรมเดียวถูกละไว้ และจุดยอดโดมเคลื่อนเข้าไปเกิน 8 มม. จากระนาบกลาง ตรวจการกดจากอีกด้านและคืนสถานะครบทุกฟองด้วย Reset All Bubbles |
| เมาส์ในฉาก | ป้อนสถานะเมาส์จำลองของ Input System ที่พิกัดจากกล้อง ทดสอบผ่านตัวรับอินพุตของเดโม พบว่าคลิกซ้ายบีบเนยและกดฟองเป้าหมายได้ คลิกขวายกบอร์ดและปล่อยให้ Rigidbody กลับมาทำงานได้ |
| XRI | ใช้ Near-Far Interactor สองตัวของ Quest Player เดิม จำลองการเลือกและอินพุต Trigger ผ่าน XRI ยืนยันการหยิบและปล่อยของเล่นทั้งสอง การบีบเนยด้วยมือที่ถือ และการเล็งกดฟองด้วยอีกมือระหว่างถือบอร์ด |
| ภาพและเรขาคณิต | เรนเดอร์ภาพจากกล้องเดสก์ท็อป ตรวจตำแหน่งของเล่น ลายพิมพ์ และลำดับสีทั้งหกแถว เทียบรูปทรงกับภาพอ้างอิง |

รอบทดสอบพบข้อความเดิมของโปรเจกต์เกี่ยวกับชนิดข้อมูล Terrain ใน URP Global Settings และข้อยกเว้นจาก UnityEditor.Search.SearchDatabase ระหว่างเข้า Play Mode การทดสอบของเล่นดำเนินต่อจนจบ

ยังไม่ได้สวมแว่นหรือใช้คอนโทรลเลอร์จริง ยังไม่ได้วัด FPS บน Quest ฟังระดับเสียง สัมผัสแรงสั่น หรือทดสอบคีย์ F/R ด้วยคีย์บอร์ดจริง ควรลองระยะเอื้อม 13 ซม. ตำแหน่งโต๊ะ และความแรงของเสียงกับแรงสั่นบนอุปกรณ์เป้าหมายก่อนนำไปใช้กับผู้เล่น
